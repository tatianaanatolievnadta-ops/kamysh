# Камыш

Сайт бренда **Камыш** — натуральный сухоцвет для интерьера.

Публичная страница: https://tatianaanatolievnadta-ops.github.io/kamysh/

## Локально

Откройте `index.html` или запустите:

```bash
python -m http.server 8765
```

## Telegram-заявки

1. Скопируйте `js/telegram-config.example.js` → `js/telegram-config.js`
2. Вставьте токен и chat_id
3. На GitHub: Settings → Secrets → Actions  
   - `TELEGRAM_BOT_TOKEN`  
   - `TELEGRAM_CHAT_ID`
